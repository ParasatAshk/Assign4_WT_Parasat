Project Modules & Tasks

Part 1: Basic HTML Forms

Explores native HTML forms with proper label-to-input association, followed by browser built-in HTML5 validation attributes.

  • Task 0: Simple Contact Form (Name, Email, Message, Submit)
  • Task 1: Built-in HTML5 validation (required, email, min/max length)
Explore Part 1

Part 2: Bootstrap Forms

Upgrades the contact form with Bootstrap 5 grid layout, modern input classes, helper text, and styled validation feedback classes.

  • Task 2: Bootstrap Form styling, grid alignment, helper texts
  • Task 3: Bootstrap feedback classes (.is-valid, .is-invalid) with JavaScript
Explore Part 2

Part 3: Advanced Registration

A complete, responsive user registration form featuring multiple input types, responsive grid columns, password matching, and comprehensive validation.

  • Task 4: Registration form with Radio, Checkboxes, Dropdown
  • Password confirmation logic, form reset, and interactive alert feedback

Area Key Elements / Classes Purpose & Outcome
