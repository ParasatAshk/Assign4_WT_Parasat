Part 1: Basic HTML Forms

Comparing a basic semantic contact form (Task 0) with a form utilizing native HTML5 built-in validation (Task 1).

Task 0 Simple Contact Form
Pure HTML

This form demonstrates standard HTML structure with dedicated <label> tags linked via matching id and for attributes. No custom styling or strict HTML5 validation is applied.

Contact Information
Task 0 Features:
  • Semantic <form> and <fieldset> tags
  • Explicit <label for="..."> for accessibility
  • Inputs: text (Name), email (Email), textarea (Message)
  • Standard Submit button
Task 1 HTML5 Validation Form
Native Validation

This form applies HTML5 validation attributes: required, type="email", minlength, and maxlength. The browser automatically blocks invalid submissions and displays native tooltips.

Validated Contact Form
How to Test Native Validation:
  1. Click submit while fields are empty → Browser stops submission: "Please fill out this field".
  2. Type "ab" into Name → Browser stops: "Please lengthen this text to 3 characters or more".
  3. Enter "notanemail" into Email → Browser stops: "Please include an '@' in the email address".
  4. Type fewer than 10 characters in Message → Browser stops with minimum length constraint.
