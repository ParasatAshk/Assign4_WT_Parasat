Task 4 Implementation Highlights & Defense Notes
Bootstrap Responsive Grid

Utilizes .row with .col-md-6 and .col-12 to render side-by-side fields on tablets/desktops and a clean single-column stacked view on mobile devices.

Password Match Validation

JavaScript compares the password and confirmPassword values on the fly. If they mismatch, confirmPassword is flagged with .is-invalid and a dynamic error message.

Radio & Checkbox Group Handling

Ensures at least one radio option is chosen for Gender and at least one checkbox is ticked for Hobbies before permitting successful submission.

Form Reset Mechanics

The Reset button not only wipes input values via native form.reset(), but also cleanly purges all validation classes (is-valid, is-invalid) and alerts.
